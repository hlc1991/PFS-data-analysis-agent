## 验收原则

1. 核心分析闭环至少完整验证一次。
2. 每次修改运行对应专项测试和完整质量门。
3. 真实模型、数据库和外部服务必须绑定具体环境单独验收。
4. 新版本必须记录 commit、CI、安装包和目标设备 smoke，不能复用旧版本结论。
5. 业务分析结果需核对字段、时间范围、指标口径、单位和数据来源。
